# Чарнік сталкера

Електронна картка персонажа для настільної гри по Зоні за правилами нашого майстра.

- Сайт: https://stalker-rpg-101a6.web.app
- Вхід через Google. Свою картку редагуєш, чужі лише читаєш.
- Майстер створення: 16 балів характеристик, 18 балів навичок, 4000 купонів.
- У картці: здоров'я з пораненнями, радіація, калькулятор пострілу, зброя, рюкзак, нотатки.

## Розробка

```bash
npm install
npm run dev
```

Адреса `http://localhost:5173/?demo` відкриває чарнік без входу й без запису в базу.

```bash
npm test
npm run deploy
```

Перед першою викладкою треба один раз виконати `npx firebase login`.

Стек: React, Vite, TypeScript, Firebase (вхід, Firestore, хостинг). Як усе влаштовано, описано в `CLAUDE.md`.
